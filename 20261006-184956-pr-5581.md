## Executive Summary

The PR adds `hostLoopback: false` for vz, which drops the gateway's `192.168.5.2 → 127.0.0.1` NAT entry. But the host then dials 192.168.5.2 on its own network, so guest connections to `host.lima.internal` hang (75 s here) instead of being refused, and ten pending ones stall all new guest TCP. A root guest still reaches host loopback over UDP through 0.0.0.0, and the new driver refusals block `limactl delete`. Each problem has a small fix.

## Important Issues

I1. **With `hostLoopback: false`, connections to `host.lima.internal` hang or reach the LAN instead of being refused** — `pkg/networks/usernet/gvproxy.go:102-104` [Claude Opus 5.5] (important, regression)

```go
	if disableHostLoopback {
		return map[string]string{}
	}
```

gvisor-tap-vsock v0.8.9's `forwarder.TCP` passes the guest's destination, translated only if the NAT table names it, to `net.Dial` with no timeout. With the empty table the host dials `192.168.5.2:<port>` on its own network. On this Mac (192.168.0.0/16 on-link) the guest got its RST after 75 s, and ten pending dials fill the forwarder's in-flight slots, so they stall every new guest TCP connection. If a LAN or VPN device holds 192.168.5.2, it gets the traffic instead.

`setupEnv` still rewrites a loopback proxy to the gateway (`pkg/cidata/cidata.go:97-102`), so proxied requests and their credentials go the same way.

The docs (`website/content/en/docs/config/network/user.md:30`) and the 67a1e1be body say these connections are refused.

```go repro
	conn    net.Conn
	wmu     sync.Mutex
	mu      sync.Mutex

func startProbeGuest(t *testing.T, disableHostLoopback bool) *probeGuest {
	logrus.SetLevel(logrus.PanicLevel)
	vn, err := virtualnetwork.New(&types.Configuration{
		MTU:               1500,
		Subnet:            "192.168.5.0/24",

	}

	g := &probeGuest{conn: b, replies: map[uint16]chan string{}}
	go g.read()
	return g
}

func (g *probeGuest) send(l ...gopacket.SerializableLayer) {
	buf := gopacket.NewSerializeBuffer()
	if err := gopacket.SerializeLayers(buf, gopacket.SerializeOptions{FixLengths: true, ComputeChecksums: true}, l...); err != nil {
		panic(err)
	}
	frame := buf.Bytes()
	prefix := make([]byte, 4)
	binary.BigEndian.PutUint32(prefix, uint32(len(frame)))
	g.wmu.Lock()
	defer g.wmu.Unlock()
	_, _ = g.conn.Write(append(prefix, frame...))
}

func (g *probeGuest) eth() *layers.Ethernet {
	gw, _ := net.ParseMAC(gatewayMacAddr)
	return &layers.Ethernet{SrcMAC: probeGuestMAC, DstMAC: gw, EthernetType: layers.EthernetTypeIPv4}
}

func (g *probeGuest) read() {
	hdr := make([]byte, 4)
	for {
		if _, err := io.ReadFull(g.conn, hdr); err != nil {
			return
		}
		frame := make([]byte, binary.BigEndian.Uint32(hdr))
		if _, err := io.ReadFull(g.conn, frame); err != nil {
			return
		}
		pkt := gopacket.NewPacket(frame, layers.LayerTypeEthernet, gopacket.Default)
		if arp, ok := pkt.Layer(layers.LayerTypeARP).(*layers.ARP); ok && arp.Operation == layers.ARPRequest && net.IP(arp.DstProtAddress).Equal(probeGuestIP) {
			reply := &layers.ARP{
				AddrType: layers.LinkTypeEthernet, Protocol: layers.EthernetTypeIPv4, HwAddressSize: 6, ProtAddressSize: 4,
				Operation: layers.ARPReply, SourceHwAddress: probeGuestMAC, SourceProtAddress: probeGuestIP,
				DstHwAddress: arp.SourceHwAddress, DstProtAddress: arp.SourceProtAddress,
			}
			e := g.eth()
			e.EthernetType = layers.EthernetTypeARP
			e.DstMAC = arp.SourceHwAddress
			go g.send(e, reply)
			continue
		}
		if tcp, ok := pkt.Layer(layers.LayerTypeTCP).(*layers.TCP); ok {
			kind := ""
			switch {
			case tcp.RST:
				kind = "RST"
			case tcp.SYN && tcp.ACK:
				kind = "SYN-ACK"
			}
			g.mu.Lock()
			ch := g.replies[uint16(tcp.DstPort)]
			g.mu.Unlock()
			if ch != nil && kind != "" {
				select {
				case ch <- kind:
				default:
				}
			}
		}
	}
}

func (g *probeGuest) syn(dst net.IP, srcPort, dstPort uint16) chan string {
	ch := make(chan string, 1)
	g.mu.Lock()
	g.replies[srcPort] = ch
	g.mu.Unlock()
	ip := &layers.IPv4{Version: 4, IHL: 5, TTL: 64, SrcIP: probeGuestIP, DstIP: dst.To4(), Protocol: layers.IPProtocolTCP}
	tcp := &layers.TCP{SrcPort: layers.TCPPort(srcPort), DstPort: layers.TCPPort(dstPort), SYN: true, Seq: 1000, Window: 65535}
	_ = tcp.SetNetworkLayerForChecksum(ip)
	g.send(g.eth(), ip, tcp)
	return ch
}

func closedLoopbackPort(t *testing.T) uint16 {
	l, err := net.Listen("tcp4", "127.0.0.1:0")
	if err != nil {
		t.Fatal(err)
	}
	port := l.Addr().(*net.TCPAddr).Port
	l.Close()
	return uint16(port)
}

// A guest connecting to a closed port on host.lima.internal: how long until it hears back?
func TestProbeClosedPortReply(t *testing.T) {
	for _, disable := range []bool{false, true} {
		g := startProbeGuest(t, disable)
		start := time.Now()
		ch := g.syn(probeGateway, 40000, closedLoopbackPort(t))
		select {
		case kind := <-ch:
			t.Logf("DisableHostLoopback=%v: %s after %.2fs", disable, kind, time.Since(start).Seconds())
		case <-time.After(90 * time.Second):
			t.Logf("DisableHostLoopback=%v: no reply within 90s", disable)
		}
	}
}

// Pending dials to host.lima.internal hold gvisor's TCP forwarder in-flight slots (limit 10),
// so a SYN to an unrelated, reachable host listener goes unanswered once ten are pending.
func TestProbeInFlightStall(t *testing.T) {
	l, err := net.Listen("tcp4", "0.0.0.0:0")
	if err != nil {
		t.Fatal(err)
	}
	defer l.Close()
	go func() {
		for {
			c, err := l.Accept()
			if err != nil {
				return
			}
			c.Close()
		}
	}()
	u, err := net.Dial("udp4", "192.0.2.1:9") // no packet is sent; this only picks the outbound interface
	if err != nil {
		t.Fatal(err)
	}
	lanIP := u.LocalAddr().(*net.UDPAddr).IP
	u.Close()
	port := uint16(l.Addr().(*net.TCPAddr).Port)

	for _, pending := range []int{9, 10} {
		g := startProbeGuest(t, true)
		for i := range pending {
			g.syn(probeGateway, uint16(41000+i), uint16(18000+i))
		}
		time.Sleep(500 * time.Millisecond)
		start := time.Now()
		ch := g.syn(lanIP, 50000, port)
		select {
		case kind := <-ch:
			t.Logf("%2d pending dials to host.lima.internal: SYN to host LAN listener %s:%d got %s after %.2fs", pending, lanIP, port, kind, time.Since(start).Seconds())
		case <-time.After(5 * time.Second):
			t.Logf("%2d pending dials to host.lima.internal: SYN to host LAN listener %s:%d got no reply within 5s", pending, lanIP, port)
		}
	}
}

// The host dials the guest's UDP destination 0.0.0.0 as is, and macOS treats 0.0.0.0 as itself.
func TestProbeUDPUnspecifiedReachesLoopback(t *testing.T) {
	for _, tc := range []struct {
		disable bool
		dst     net.IP
	}{
		{false, probeGateway},
		{true, probeGateway},
		{true, net.IPv4zero},
	} {
		ul, err := net.ListenUDP("udp4", &net.UDPAddr{IP: net.IPv4(127, 0, 0, 1)})

			t.Fatal(err)
		}
		g := startProbeGuest(t, tc.disable)
		ip := &layers.IPv4{Version: 4, IHL: 5, TTL: 64, SrcIP: probeGuestIP, DstIP: tc.dst.To4(), Protocol: layers.IPProtocolUDP}
		udp := &layers.UDP{SrcPort: 45123, DstPort: layers.UDPPort(ul.LocalAddr().(*net.UDPAddr).Port)}
		_ = udp.SetNetworkLayerForChecksum(ip)
		g.send(g.eth(), ip, udp, gopacket.Payload("probe"))
		_ = ul.SetReadDeadline(time.Now().Add(2 * time.Second))
		buf := make([]byte, 64)
		n, _, err := ul.ReadFromUDP(buf)
		t.Logf("DisableHostLoopback=%v dst=%s: 127.0.0.1-only UDP listener received payload=%v", tc.disable, tc.dst, err == nil && string(buf[:n]) == "probe")
		ul.Close()
	}
}
```

I2. **A root guest still reaches host loopback over UDP through 0.0.0.0** — `templates/default.yaml:695-698` [Codex GPT 6 Astra] (important, gap)

```yaml
# When false, the guest cannot reach the host's loopback services (those bound to 127.0.0.1 or
# to all interfaces) via "host.lima.internal" (192.168.5.2) on the default user-mode network.
# DNS, outbound access to other hosts and `limactl shell` keep working.
# Set this to false for a guest that runs untrusted code, such as a CI runner.
```

The UDP forwarder also dials the untranslated destination on the host, and macOS treats a dial to 0.0.0.0 as one to itself. A guest that can send raw packets can therefore deliver datagrams to any host service bound only to 127.0.0.1, with or without the NAT entry. Root can, and the issue's threat model assumes a root guest. The path predates the PR, but the PR now recommends the option for untrusted code. A TCP SYN to 0.0.0.0 did not get through in a frame probe, so only UDP is shown.

## Design Observations

### Concerns

- (in-scope) Five copied denylist refusals cover the built-in drivers. An external driver from the registry sees none of them and silently ignores `hostLoopback: false`, which fails open for an isolation option. An allowlist that start-time code checks, such as a `driver.Info.Features` flag, would close the class and replace the copies. It has to stay off the load path (see Acknowledged Limitations). [Claude Opus 5.5]
- (future) gvisor-tap-vsock v0.8.9 cannot drop traffic to a destination, so the I1 remap relies on macOS having no route to 0.0.0.1. A blocked-destination option upstream would make the refusal independent of host routing. [Claude Opus 5.5, Codex GPT 6 Astra]

### Strengths

- The default is unchanged, and every unsupported driver, plus `user-v2`, rejects `false` instead of ignoring it. [Claude Opus 5.5, Codex GPT 6 Astra, Gemini 3.1 Pro, Gemini 3.5 Flash]
- The `knownYamlProperties` entries keep the filled-in default from triggering "ignoring" warnings on every start. [Claude Opus 5.5]
- `TestFillDefaultHostLoopback` covers the precedence of `default.yaml`, the instance and `override.yaml`. [Claude Opus 5.5, Codex GPT 6 Astra, Gemini 3.5 Flash]
- DNS on vz does not depend on the removed entry. vz guests resolve through gvisor's own listener on the gateway (`pkg/cidata/cidata.go:327-328`), while other drivers DNAT through the gateway to the hostagent's resolver, which is why krunkit stays excluded. [Codex GPT 6 Astra, Gemini 3.5 Flash]

## Review Process Notes

### Skill improvements

- When a change claims to block traffic by removing a rule (a NAT or port-forward entry, a route, an allowlist entry), find the code that handles that traffic once the rule is gone and drive it with a real packet or connection, timing the result. A fallthrough handler usually forwards unmatched traffic somewhere else instead of rejecting it, and a probe with a short deadline cannot tell a refusal from a hang.
- When a change adds an option documented as isolation for untrusted code, list the other addresses that reach the protected target (the unspecified address, aliases, other interfaces) and test each one, because the documented guarantee covers them all.

When a proxy hostname (like `localhost`) resolves to multiple loopback IPs (e.g., `127.0.0.1` and `::1`), the loop executes for each one. On the second iteration, the newly added warning logs this already-mutated value, producing a confusing output: `"http_proxy" value "http://192.168.5.2:8080/" points at the host's loopback...`. This misleads users into thinking `192.168.5.2` is a host loopback address. 

Fix: Break out of the loop after the first successful rewrite to prevent double-evaluation and avoid logging the mutated value.

##### Executive Summary

PR #5581 adds `hostLoopback` to `lima.yaml` (defaulting to `true`) to allow blocking guest access to host loopback services on the `vz` driver by omitting the gateway NAT entry in `gvisor-tap-vsock`. ###### Concerns

1. **Lifecycle coupling in driver validation** `(in-scope)`:
Placing driver rejection logic in `validateConfig` causes `driver.Configure` to fail during teardown and maintenance routines (`instance.Delete`, `cmd/limactl/factory-reset.go`, and `pkg/snapshot/snapshot.go`).
