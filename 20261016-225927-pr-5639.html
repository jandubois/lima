Executive Summary ¶

The hostagent now supervises the ssh ControlMaster, restarts it, and replays the guestSocket, static and SSH-forwarder TCP forwards, while Lima clients move to ControlMaster=no. The design holds, but the master's new keepalive options turn CI's test-misc job red. A keepalive timeout ends ssh without closing its channels, so every open mux session's stdio stays non-blocking, and Ansible then refuses to run. Every start also waits an extra 3 s, and no test reaches the foreign-master takeover.

After This Review ¶

The findings were addressed in ebcada44, amended into the PR commit, so the code they cite has changed since the review ran. Each finding ends with its outcome.

# Save as probe-nonblock-leak.py; run: python3 probe-nonblock-leak.py
# Needs key-based `ssh localhost` (BatchMode). Starts an ssh ControlMaster to
# localhost, opens a mux session whose stderr is a pipe (standing in for a CI
# step's stderr), ends the master with its connection hung or closed, and
# reports the pipe's O_NONBLOCK flag after the master has exited.
import fcntl, os, signal, subprocess, tempfile, time

def nonblock(fd):
    return bool(fcntl.fcntl(fd, fcntl.F_GETFL) & os.O_NONBLOCK)

def run(label, keepalive, end):
    d = tempfile.mkdtemp(prefix="nb", dir="/tmp")
    ctl = ["-o", "ControlPath=" + d + "/s", "-o", "BatchMode=yes"]
    alive = ["-o", "ServerAliveInterval=1", "-o", "ServerAliveCountMax=2"] if keepalive else []
    master = subprocess.Popen(
        ["ssh", "-o", "ControlMaster=yes", "-o", "ControlPersist=no"] + alive + ctl + ["-N", "localhost"],
        stdin=subprocess.DEVNULL, stdout=subprocess.DEVNULL, stderr=subprocess.PIPE)
    while subprocess.run(["ssh"] + ctl + ["-O", "check", "localhost"], capture_output=True).returncode != 0:
        time.sleep(0.2)
    r, w = os.pipe()
    client = subprocess.Popen(
        ["ssh", "-o", "ControlMaster=no"] + ctl + ["localhost", "echo $PPID; sleep 30"],
        stdin=subprocess.DEVNULL, stdout=subprocess.PIPE, stderr=w)
    server_pid = int(client.stdout.readline())  # the sshd process serving the master's connection
    time.sleep(0.5)
    before = nonblock(w)
    end(server_pid, ctl)
    master.wait(timeout=30)
    client.wait(timeout=30)
    after = nonblock(w)
    try:
        os.kill(server_pid, signal.SIGKILL)
    except ProcessLookupError:
        pass
    reason = master.stderr.read().decode().strip().splitlines()
    print(f"{label}: master exit={master.returncode} ({reason[-1] if reason else 'no message'}); "
          f"stderr O_NONBLOCK during session={before}, after master exit={after}")
    os.close(r)
    os.close(w)

def hang(pid, ctl):
    os.kill(pid, signal.SIGSTOP)

def close(pid, ctl):
    os.kill(pid, signal.SIGTERM)

def hang_then_exit(pid, ctl):
    os.kill(pid, signal.SIGSTOP)
    time.sleep(3)
    subprocess.run(["ssh"] + ctl + ["-O", "exit", "localhost"], capture_output=True)

run("hung, keepalive times out ", True, hang)
run("closed by the server      ", True, close)
run("hung, ended with -O exit  ", False, hang_then_exit)

Review Process Notes ¶

Skill improvements ¶

  • When a change alters how a long-lived child process ends (a new timeout, keepalive, signal, or kill fallback), compare the cleanup that each exit path runs. An abnormal exit often skips restoring state the process shares with others, such as file-descriptor flags, terminal modes, or lock and socket files, which the orderly path restores.

Repo context updates ¶

  • An ssh ControlMaster sets O_NONBLOCK on the stdio that each mux client hands it and clears the flag only when it exits in an orderly way. A master that ends on a keepalive timeout, a fatal error or SIGKILL leaves those descriptors non-blocking for the client's parent and every later process sharing them, which breaks ansible-playbook in CI. Flag any change that lets the master exit that way while sessions may be open.
  • The test-misc.yaml template job's online-snapshot step rewinds the guest under a live ssh master, so it is the one CI job where the master hangs and dies with a mux session open. Read its log for any change to the master's lifetime or exit path.
  • Until the events watcher sets nxadm/tail's CompleteLines, a limactl start fatal "failed to unmarshal … as events.Event: unexpected end of JSON input" is an older partial-line race, not a regression of the PR under review.
