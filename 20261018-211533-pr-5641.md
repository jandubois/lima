I1. **Deleting the UTF-8 guard silently rewrites a path, and no test notices** — `pkg/textutil/textutil.go:122-124` [Codex GPT 6 Astra, Claude Opus 5.5, Gemini 3.5 Flash]

```go
		if !utf8.ValidString(s) {
			return "", fmt.Errorf("value is not valid UTF-8: %q", s)
		}
```

`TestXMLFuncRejectsInvalidXMLChar` feeds U+0001, which is valid UTF-8, so it reaches the range check after this guard and never the guard itself. Without the guard, `range s` decodes each invalid byte as U+FFFD, the range check accepts U+FFFD, and `xml.EscapeText` writes it in place of the byte. A `LIMA_HOME` or `PATH` containing a Latin-1 byte would then install a plist that names a different directory, and nothing would report it. The probe below deletes the guard, shows the rewrite, and runs every package that renders a plist; all of them pass. Because nothing reports the rewrite, the test is required.

## Design Observations

### Concerns

- **(in-scope) A control character now fails a render that Apple's parser accepted.** At the merge-base, a `PATH` holding ESC rendered into a plist that `plutil -lint` accepts and reads back intact; with this PR, the render fails, so `limactl autostart enable` would fail. ## Review Process Notes

**Skill improvements**

- When the PR head was force-pushed shortly before the review, fetch the previous head, diff its tree against the reviewed one, and check the commit message and PR body against the reviewed tree. A last-minute rewrite can leave the commit message and PR body describing the version that it replaced.
- Splice every patch and probe output into the report from the file that produced it. The tool layer decodes `\u` escapes in typed text, so a retyped Go string literal reaches the file as the raw character.
- A finding about a commit message cites the short SHA, and the citation lint warning that it draws is expected.

**Repo context updates**

- [repo] `TestRenderTemplate` in `pkg/autostart` compares the whole rendered launchd and systemd units, with `KeepAlive` set and unset, so a template edit that swaps or drops a field fails it. A narrower test of the same templates need not re-check field placement.
- [repo] `pkg/plist` decodes XML plists. A test that checks values in a rendered launchd plist should decode with it instead of hand-writing a decoder.
- [repo] `textutil.TemplateFuncMap` serves both internal templates, through `ExecuteTemplate`, and the user-facing `limactl list --format`. An entry in `FuncHelp` publishes the function in the CLI help and the generated docs.
