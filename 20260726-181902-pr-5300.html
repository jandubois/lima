Executive Summary ¶

The change pins both halves of a Windows reverse-sshfs mount (the host path form and the local sftp-server) to the one ssh.exe Lima resolved at startup. This gives sshutil.SftpServerForSSH its first caller. The mechanism is sound. But two log lines misreport ordinary setups, the pairing this PR exists to establish has no test, and the ssh transport itself stays unpinned.

Four reviewers ran the same prompt. Gemini 3.1 Pro reported nothing; Gemini 3.5 Flash reported one finding that verification rejected. Claude and Codex agreed on the substance.

	// convention; stock Cygwin defaults to /cygdrive/c/. Only an absolute
	// drive-letter path ("C:\foo") has a well-defined form here. A
	// drive-relative path ("C:foo") would become an unrelated absolute
	// path, so reject it.
	if !filepath.IsAbs(orig) {
		return "", fmt.Errorf("cannot convert %#q to an MSYS-style path: input is not an absolute drive-letter path", orig)
	}

	// UNC path ("\\server\share\foo") is rejected here.
	if vol := filepath.VolumeName(orig); len(vol) == 2 && vol[1] == ':' {
		// orig[2:] starts with a separator for an absolute drive path
		// (C:\foo, C:/foo); strip it so the result stays canonical.

		logrus.Debugf("native cygpath fallback: %#q -> %#q", orig, converted)
		return converted, nil
	}

	return "", fmt.Errorf("cannot convert %#q to an MSYS-style path: input is not an absolute drive-letter path", orig)
}

Design Observations ¶

Concerns ¶

  1. The converted path also becomes the guest's sshfs base path (in-scope) Claude Opus 5. sshocker uses LocalPath twice: as the -d root of the local sftp-server, which this PR pairs, and as the guest's sshfs ':'+LocalPath argument, which it does not. On the native branch the guest now receives :C:/Users/jan where every earlier form began with /. Reading sshfs 3.7.3 settles most of it: find_base_path scans forward to the first colon, so the base path is C:/Users/jan, and buf_add_path prepends it verbatim with no realpath expansion. Two residual questions remain for the deferred plain-Windows run. Win32 OpenSSH's sftp-server must resolve a drive-letter path in SSH_FXP_LSTAT, since sftp_check_root requires it to stat as a directory. And transform_symlink returns early unless the base path starts with /, so absolute symlinks inside the mount stop being rewritten.
  2. The "single ssh.exe" invariant stops short of the transport (in-scope) Codex GPT 5.6 Sol Claude Opus 5. sshocker's SSHConfig.Binary() is a hardcoded return "ssh" in both v0.3.9 (pinned at go.mod:10) and v0.3.11, so PATH picks the ssh that carries the mount, not a.sshExe. Every other ssh invocation in Lima execs sshExe.Exe (pkg/copytool/rsync.go:74, pkg/mcp/toolset/toolset.go:48, cmd/limactl/shell.go:464, cmd/limactl/tunnel.go:114); reverse-sshfs is the exception. pickCompleteSSHOnWindows can select an ssh that exec.LookPath("ssh") would not, because it skips a PATH directory missing scp.exe and falls back to %SystemRoot%\System32\OpenSSH, which need not be on PATH. In that last case the mount fails outright. Any sshExe.Args from $SSH are dropped too. Closing this needs a Binary field upstream in sshocker, and nothing here makes it worse.

Review Process Notes ¶

Skill improvements ¶

  • When a change alters the format of a value that is handed to a third-party library (a path, a URL, an identifier), read the library's source and enumerate every place it forwards that value, not only the consumer the change targets. A library's field documentation names its primary use and stays silent about the rest, so a format that satisfies one consumer can break a second one in the same call. Flag any such value whose other consumers the change does not account for.
  • Verify a finding's supporting citations, not only its own file:line. When a finding argues from precedent elsewhere in the project (a named test, helper, or convention "already used" in a sibling area), confirm that reference exists at the review SHA. An agent working from a series of related branches will cite work that has not merged, and the citation reads as established practice.
