## Critical Issues

C1. **Running MSYS2 setup before `Unit tests` turns `Windows tests (WSL2)` red** — `.github/workflows/test.yml:168-171` [Claude Opus 5.5, Codex GPT 6 Astra, Gemini 3.1 Pro, Gemini 3.5 Flash]

```yaml
    - uses: $/.github/actions/windows_wsl2_setup
    - uses: $/.github/actions/windows_msys2_prep
    - name: Unit tests
      run: go test -v ./...
```

`windows_msys2_prep` puts `C:\msys64\usr\bin` on PATH and installs rsync ahead of `go test`. `TestRsyncCommandPaths` was added upstream in `1e6e2b38` and skips without rsync, as it did at the merge-base. Now all seven subtests run and fail, expecting `C:\Users\...` where the code emits `/c/Users/...`.

The code is right. `pkg/copytool/rsync.go:129` converts each local operand with the cygpath beside the rsync, because a Cygwin or MSYS rsync reads `C:` as a host. Branch protection requires only `DCO`, yet merging this as-is stops every later PR's WSL2 job at `Unit tests`, before its integration steps.

## Review Process Notes

### Skill improvements

- Fetch the head commit's CI results before launching agents, not only before consolidating, and put each failing job's error excerpt, with the same job's outcome at the merge-base, into the prompt. Agents cannot reach CI themselves. With the failure in hand they spend the round on its cause and its fix, and a failure first seen at consolidation gets the orchestrator's analysis alone.
- When a change alters what runs before a test step (installs a tool, moves setup ahead of the test command, changes PATH), list the tests that skip when that tool is absent and check them against the new environment. A skip guard keyed on a tool's presence turns an environment change into newly running code the diff does not show.

### Repo context updates

- [repo] On Windows, limactl appends `%PROGRAMFILES%\QEMU` and `C:\msys64\usr\bin` to its own PATH whenever those directories exist (`envutil.PlatformCommonToolDirs`, applied in `cmd/limactl/main.go`). Removing a toolchain from PATH therefore does not hide it from limactl; only deleting the directory does. Review any Windows change to toolchain isolation, PATH handling or plain-host testing with that append in mind.
- [repo] Lima's default vmType on Windows is QEMU (`limatype.DefaultDriver`). Prose claiming that Windows prefers WSL2 is wrong.
- [repo] Branch protection on `master` requires only the `DCO` check, and the branch has no rulesets (checked 2026-10-01). A red CI job does not block a merge mechanically, so rate its severity by what the red job stops covering for every later PR.
